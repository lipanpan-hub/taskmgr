`tm ui`
=======

启动 Web UI 服务

* [`tm ui`](#tm-ui)
* [`tm ui run`](#tm-ui-run)
* [`tm ui start`](#tm-ui-start)

## `tm ui`

启动 Web UI 服务

```
USAGE
  $ tm ui [-p <value>]

FLAGS
  -p, --port=<value>  [default: 3000] 指定服务端口

DESCRIPTION
  启动 Web UI 服务

ALIASES
  $ tm ui start
  $ tm ui run

EXAMPLES
  $ tm ui

  $ tm ui --port 8080
```

_See code: [src/commands/ui/index.ts](https://github.com/lipanpan-hub/taskmgr/blob/v2.3.27/src/commands/ui/index.ts)_
